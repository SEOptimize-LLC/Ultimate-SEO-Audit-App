is not a URL substring. This has now been fixed five separate times in different
files: 1.2 crawl targets, 1.3 scope, 1.4 template grouping, 1.5 scope, and the
workbook builder. Any new code that classifies URLs must use
`crawl_targets.collect()`, which reads sitemap group names, rather than matching
patterns against the URL.
